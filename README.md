# Integration Architect Study

Study material for enterprise integration architecture, with a focus on Boomi.

## Contents

| Folder | What is in it |
|---|---|
| [01-integration-patterns](01-integration-patterns/) | **MasterIntegration-Patterns.pdf** (45 pages: topology, messaging, interaction, data, routing, resilience, channels, message construction, migration, Boomi mapping, selection guide) and a one-page-per-pattern cheatsheet |
| [02-event-driven-architecture](02-event-driven-architecture/) | Event-driven architecture: broker and mediator topologies, event mesh, CQRS, event sourcing, outbox, idempotency, CloudEvents, AsyncAPI, schema evolution |
| [03-boomi](03-boomi/) | Boomi reference material (shapes, connectors, Agentstudio) |
| [04-interview-prep](04-interview-prep/) | Generic interview preparation notes |

Each pattern document has diagrams, a use case, sample code and trade-offs.
